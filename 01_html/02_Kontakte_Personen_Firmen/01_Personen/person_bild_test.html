Person Image Gallery

Fetch and display images with byte array conversion

How to Use

Enter a person ID in the input field below and click "Fetch Images" to retrieve and display all images from the web service.

The application will call your web service at: http://localhost:5000/person/bild/[ID]

Each image is returned with ID field PK_BILD_BILDER and image content in FILECONTENT.

Data Processing Information

The application processes the image data using the following conversion logic:

// Convert the bytea data to a Uint8Array
let byteArray;
if (image.FILECONTENT.data instanceof Array) {
    byteArray = new Uint8Array(image.FILECONTENT.data);
} else if (image.FILECONTENT.data instanceof Uint8Array) {
    byteArray = image.FILECONTENT.data;
} else if (typeof image.FILECONTENT.data === 'string') {
    // Handle base64 encoded string
    const binaryString = atob(image.FILECONTENT.data);
    const bytes = new Uint8Array(binaryString.length);
    for (let i = 0; i < binaryString.length; i++) {
        bytes[i] = binaryString.charCodeAt(i);
    }
    byteArray = bytes;
} else {
    console.warn('Unsupported FILECONTENT data format:', typeof image.FILECONTENT.data);
    continue; // Skip to next image
}

// Create a Blob from the byte array
const blob = new Blob([byteArray], { type: 'image/jpeg' });

// Create an object URL from the Blob
const imageUrl = URL.createObjectURL(blob);
