    Help & Instructions

    How to Use:

    1. Open & Refresh Folders:

    • Click "Open Folder" to select a folder with images
    • Use "Refresh" button to reload the current folder
    • Click folders in the explorer to navigate
    • Use breadcrumb to jump to parent folders

    2. Browse & Select Images:

    • Click on image files to select them
    • Use Previous/Next buttons to navigate through images
    • Selected image appears in the preview area

    3. Full Screen View:

    • Click the image or press "Full Screen" button
    • Use F key to toggle full screen
    • Navigate images in full screen mode
    • Use zoom controls to adjust view
    • Press ESC or click X to exit full screen

    4. Rotate Images:

    • Use rotation buttons for common angles
    • Drag the slider for precise rotation control
    • Click "Custom" to enter a specific angle
    • Multiple rotations can be applied sequentially

    5. Save & Manage:

    • Click "Save Image" to save rotated version
    • Use "Reset All" to clear rotation and zoom
    • Original files are never modified

    Keyboard Shortcuts:

    • F: Toggle full screen
    • ← / →: Previous/Next image
    • + / -: Zoom in/out
    • 0: Reset zoom
    • R: Reset rotation
    • Ctrl + S: Save image
    • ESC: Exit full screen / close modals
    • F5: Refresh folder

    Supported Formats:

    • JPEG/JPG (.jpg, .jpeg)
    • PNG (.png)
    • GIF (.gif)
    • WebP (.webp)
    • BMP (.bmp)
    • SVG (.svg)
