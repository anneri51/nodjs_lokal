 Web Service Information

            
This application uses the following web service endpoints:

            
GET: http://localhost:5000/termine

            
GET Single: http://localhost:5000/termine/:id

            
POST: http://localhost:5000/termine/insert

            
PUT: http://localhost:5000/termine/update/:id

            
DELETE: http://localhost:5000/termine/delete/:id

            
GET Today: http://localhost:5000/termine/today

            
GET Statistics: http://localhost:5000/termine/statistics

            
GET Range: http://localhost:5000/termine/range/:from/:to

            

                
                Data is loaded in real-time from the web service. Click "Refresh" to update.
