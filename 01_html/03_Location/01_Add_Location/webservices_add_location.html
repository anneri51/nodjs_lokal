Web Services Dashboard

List of all web services used in the application

Address Services

POST
http://localhost:5000/add_strasse
Adds a new street to the database.
Parameters:
  • FK_ADR_ORT Foreign key to the city table
  • STRASSE Street name
POST
http://localhost:5000/add_rel_plz_ort_strasse
Creates a relationship between ZIP code, city, and street.
Parameters:
  • FK_ADR_PLZ_ORT Foreign key to the ZIP code/city table
  • FK_ADR_STRASSE Foreign key to the street table
POST
http://localhost:5000/add_strasse_hsnr
Adds a house number to a street.
Parameters:
  • FK_REL_ADR_PLZ_ORT_STRASSE Foreign key to the relationship table
  • HSNR House number
POST
http://localhost:5000/add_addresse
Adds a complete address to the database.
Parameters:
  • STRASSE Street name
  • HSNR House number
  • BEZEICHNUNG Designation/name
  • FK_ADR_PLZ_ORT Foreign key to ZIP code/city table
  • FK_ADR_STRASSE_HSNR Foreign key to street/house number table
  • FK_ADR_REGION Foreign key to region table
  • KOORDINATEN Coordinates
  • COMM Comments
POST
http://localhost:5000/upd_adr_adresse_schnell
Updates a quick address record.
Parameters:
  • pk_adr_adresse_schnell Primary key of the quick address record
  • fk_adr_adresse Foreign key to address table (optional)
  • fk_loc_location Foreign key to location table (optional)

Location Services

POST
http://localhost:5000/add_location
Adds a new location to the database.
Parameters:
  • LOCATION_NAME Name of the location
  • LOCATION_TYPE Type of location
  • FK_ADR_ADRESSE Foreign key to address table
  • KOORDINATEN Coordinates
  • COMM Comments

Retrieves all regions from the database.

GET
http://localhost:5000/rel_plz_ort_strasse/{plzOrtId}

GET
http://localhost:5000/strasse_hsnr/{streetId}

GET

GET
http://localhost:5000/adr_adresse_schnell

GET
http://localhost:5000/location

GET
http://localhost:5000/land

GET
http://localhost:5000/location_type
